# 第三周作业：上市公司财报问答知识库（方向 A）

## 交付摘要

- **方向：A**
- **材料：** 10 家食品饮料相关 A 股上市公司 2024 年年度报告全文，下载地址均写在 `config/companies.json`，来自巨潮资讯网官方静态 PDF。
- **切块：** 按 PDF 页解析，约 900 字/块、160 字重叠；每块保留公司、代码、行业、报告年份、PDF 页码、章节和块 ID。
- **索引：** BM25 词法索引 + 256 维可复现本地向量特征，检索时按 0.55/0.45 混合排序。
- **页面：** `web/server.mjs` 提供本地问答页，证据以 `C1/C2...` 标记，并显示公司、章节和 PDF 页码。
- **评测：** `data/questions.json` 有 10 道题，其中 Q09、Q10 为跨公司的全景题；`data/evaluation.csv` 记录召回块、判断和错误原因。

## 运行

```powershell
npm install
npm run all
npm run serve
```

浏览器打开 `http://localhost:8787`。如果已经下载并建立索引，单独运行 `npm run serve` 即可。

## 仓库安全

财报 PDF、抽取出的 JSON 和生成索引已写入 `.gitignore`，仓库不提交原始 PDF、API key、密码或个人账号。下载脚本保留了资料来源，其他人可重新下载和建库。
